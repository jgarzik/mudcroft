# Mudcroft Docs

This directory holds plans and research: material about what Mudcroft
might become. How the code works today is documented next to the code in
[mudd/docs/](../mudd/docs/).

## Plans and research

- [roadmap.md](roadmap.md): everything planned but not built, plus verified
  known issues in the current server.
- [blockchain.md](blockchain.md): the parked design for blockchain payments
  and wallets.
- [research/mobile-iap-blockchain-bridge.md](research/mobile-iap-blockchain-bridge.md):
  research note on bridging mobile in-app purchases to on-chain settlement.
